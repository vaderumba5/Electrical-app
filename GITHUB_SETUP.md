# GitHub / Codex setup

Repositorio recomendado: `app-electrica`

1. Crear un repositorio vacío en GitHub, preferiblemente **privado** mientras la aplicación esté en desarrollo.
2. No inicializarlo con README, `.gitignore` ni licencia: este paquete ya contiene los archivos base.
3. Subir el contenido de esta carpeta a la rama `main`.
4. En Codex, seleccionar el repositorio y usar como primera instrucción:

   `Lee AGENTS.md y ejecuta la tarea definida en CODEX_START_HERE.md.`

`AGENTS.md`, `ARCHITECTURE.md` y `docs/` son la fuente de verdad técnica del proyecto.
